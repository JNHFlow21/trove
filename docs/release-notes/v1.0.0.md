# TROVE v1.0.0

TROVE v1 is a macOS-only, local-private capability runtime for external
Agents. MCP is the primary interface; the CLI is the diagnostic and recovery
interface. Both use the same `trove/1` capability handlers and return bounded,
cited JSON envelopes.

## Install and connect

A release set contains one `trove-runtime` wheel, one independently verifiable
source Provider wheel, and `distribution-manifest.json`.

```bash
trove version
trove --vault "$TROVE_VAULT_ROOT" doctor
trove --vault "$TROVE_VAULT_ROOT" start
trove-mcp --pack standard --vault "$TROVE_VAULT_ROOT"
```

Use `standard` for ordinary recall and search, `operations` for controlled
mutations, and `admin` for sync, Provider, and repair capabilities. Run
`agent-switch doctor` before updating the central MCP registration and
`agent-switch reconcile` afterward.

## Verified Agent outcomes

- Exact recall returns cited timelines with explicit coverage and an opaque
  cursor only when another page is required.
- Search plus context stays within two calls for an ordinary task.
- Group summary, profile, file recall, and media enrichment preserve citation
  provenance and typed failure recovery.
- Account discovery and ambiguity handling work for multi-account Vaults.
- Approval decisions remain human-only at the controlling terminal.
- Provider status, incremental sync, and existing Vault citations remain
  readable without a full reindex.

The six official Skills are `trove-recall`, `trove-group-summary`,
`trove-search`, `trove-profile`, `trove-file-recall`, and
`trove-media-enrichment`.

## Release proof

Promotion is fail-closed. The final release manifest is generated only after
the same clean distribution completes automated Agent acceptance, clean
source-free install, real-Vault redacted acceptance, upgrade/rollback drill,
installed-consumer audit, privacy scan, and the full release gate. There is no
time-based dogfood or stability-observation promotion gate. The manifest binds
the source commit, distribution, runtime, catalog, Provider, test, performance,
cutover, and acceptance hashes at
`dist/v1.0.0-release-manifest.json`; generated release proof is not committed
to the source repository.
